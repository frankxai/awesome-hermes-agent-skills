# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone who takes part in issues, pull requests and discussions is expected to follow it.

In short: be kind, assume good faith, critique work rather than people, and keep promotion out of review threads.

## Reporting

To report a problem privately, use the maintainer's private reporting channel: **TO BE SET BY FRANK BEFORE MERGE** (see frankxai/agentic-ops#113, decision 6). Reports are kept confidential. Enforcement follows the Covenant's graduated steps: correction, warning, temporary ban, permanent ban.
